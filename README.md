# WinSight AI v1.1.1

Desktop MVP สำหรับอ่าน Windows Application/System Events แบบ read-only พร้อมสรุปหลักฐานในเครื่องและ AIForThai Pathumma

## เริ่มใช้ EXE

1. แตก ZIP ทั้งโฟลเดอร์ เก็บ `_internal` ไว้ข้าง WinSightAI.exe
2. ใส่ `.env` ข้าง EXE: `AIFORTHAI_API_KEY=คีย์ของคุณ` โดยใช้คีย์ AIForThai ที่มีสิทธิ์ Pathumma TextQA ไม่รวมคีย์ในแพ็กและไม่ส่งคีย์ในแชต คีย์ที่เคยเปิดเผยควรหมุนใหม่
3. เปิด WinSightAI.exe ส่วน Local, History, Export และการอ่าน log ไม่ต้องใช้คีย์

## เลือกช่วงวันและเวลา

- Auto Scan อ่านย้อนหลังตามจำนวนชั่วโมง 1–168 ชั่วโมง
- ปุ่ม `วัน` เปิดปฏิทิน เลื่อนเดือนและเลือกวัน หรือพิมพ์วันแบบ YYYY-MM-DD (ปี ค.ศ.)
- พิมพ์เวลาเริ่ม/สิ้นสุด HH:MM หรือ HH:MM:SS แล้วกด `Scan ช่วงวัน/เวลา`
- เวลาในช่องเป็นเวลาไทย UTC+7 เลือกช่วงได้สูงสุด 31 วัน และเวลาเริ่มต้องมาก่อนสิ้นสุด
- เลือกสูงสุด 100/200/500 เหตุการณ์ต่อหมวด Application/System รวมเฉพาะ Critical/Error/Warning
- เมื่อถึงเพดาน จะระบุว่าภาพรวมครอบคลุมเฉพาะรายการใหม่ที่สุดที่อ่านมา ลดช่วงเวลาเพื่อดูครบมากขึ้น
- ไม่ล้าง log เปลี่ยนบริการ แก้ registry หรือแก้ระบบ ถ้าอ่านไม่ได้จะแจ้ง channel ที่ไม่มีสิทธิ์

## อ่านผล

Analyze (Local) แสดงจำนวนเหตุการณ์จริง จำนวน Error/Warning/Critical ช่วงเวลาที่พบ และกลุ่มหลักฐาน [E001] เป็นต้น ชื่อกลุ่มและรหัสอ้างอิงสร้างจาก log จริง ไม่ใช่ข้อความจากโมเดล จัดกลุ่มตาม Channel/Provider/Event ID/Level/ข้อความ โดยละค่าตัวเลข SID เฉพาะตอนเทียบข้อความ กลุ่มที่ CLSID/APPID หรือรหัส error ต่างกันยังแยกจากกัน ตัวอย่างข้อความใช้เหตุการณ์แรกในกลุ่ม ต้นฉบับทั้งหมดคงอยู่ท้ายรายงาน

Import TXT รองรับ UTF-8 (.txt/.log) และอ่านเฉพาะหลักฐานเมื่อเปิดรายงาน WinSight เดิม ป้องกันสรุป AI เดิมปนเข้า log

## AI Summary

ใช้ AIForThai Pathumma TextQA: https://api.aiforthai.in.th/textqa/completion ตาม SDK ทางการ https://github.com/AIforThai/aiforthai/blob/main/aift/multimodal/textqa.py

รับเอกสาร 1–10,000 คำตามตัวตัดคำ PyThaiNLP newmm ก่อนส่งจัดกลุ่ม log ซ้ำเป็นบัตรหลักฐาน มีจำนวนจริง เวลาต้น/ท้าย Event ID Provider และข้อความตัวอย่าง ไม่มีการเติมข้อความซ้ำหรือแกล้งให้ผ่านจำนวนคำ กลุ่มยาวมากแบ่งข้อความเป็นตอนและระบุชัดว่าเป็นกลุ่มเดียวกัน เอกสารทั่วไปที่ไม่มีหัว event ใช้ข้อความเดิมแบ่งตามบรรทัด

ส่งหลักฐานทีละกลุ่ม ไม่รวมหลายกลุ่มในคำขอเดียว แต่ละตอนมีไม่เกิน 3500 ตัวอักษรสำหรับ log ที่มีโครงสร้าง (งบของแอป ไม่ใช่การยืนยันขีดจำกัดบริการ) ตอบภาษาไทย แยกข้อเท็จจริงออกจากข้อสันนิษฐาน ไม่เสนอคำสั่งแก้ระบบ โปรแกรมติดรหัสหลักฐานในรายงานเองเพราะแต่ละคำขอมีแค่หนึ่งกลุ่ม จึงไม่บังคับให้โมเดลพิมพ์รหัส E หากโมเดลอ้างรหัสที่ไม่ได้ส่งยังถือว่าไม่ผ่านคุณภาพ

ตรวจคำตอบอังกฤษ ข้อความซ้ำในย่อหน้า คำตอบตัดค้างที่ตรวจได้ Event ID/error code/GUID/SID/รุ่น Windows/วันเวลา/จำนวนครั้งที่ไม่ตรงหลักฐาน และคำสั่งเปลี่ยนระบบบางประเภท หากไม่ผ่านให้สร้างใหม่หนึ่งครั้ง ถ้ายังไม่ผ่านจะระบุ `quality_failed` และทำชุดถัดไปต่อ โดยไม่รับผลนั้นเป็นสำเร็จ

กรณีคีย์/สิทธิ์/โควตา/เครือข่าย/HTTP ผิดพลาด จะหยุดเรียกเพิ่มในรอบนั้นเพื่อไม่ส่งคำขอที่ล้มเหลวต่อเนื่อง Local summary ยังใช้ได้ ไม่แปลว่าระบบ Windows เสีย

`AI / ลองส่วนที่เหลือ` ทำต่อเฉพาะชุดไม่สำเร็จ เก็บผลเดิมเมื่อ source hash, prepared-part hash และเกณฑ์คุณภาพตรงกัน `ส่งใหม่ทั้งหมด` เริ่มใหม่ทุกชุด รอบหนึ่งส่งสูงสุด 12 ชุดใหม่ (ไม่เกิน 24 requests หากทุกชุดต้องแก้ภาษา) ที่เหลือระบุยังไม่ส่งและกดทำต่อได้ เอกสารเปลี่ยนจะไม่ใช้ผลเก่าปน เกณฑ์ฉบับนี้ต่างจาก v1.1.0 และรุ่นก่อน จึงสร้างผลใหม่เมื่อเปิด History รุ่นเก่า

ตัวตรวจเป็น heuristic ช่วยกรองข้อผิดพลาดที่พบ ไม่รับประกันความถูกต้องของภาษา การให้เหตุผล หรือสาเหตุทุกประโยค การจัดกลุ่มใช้ข้อความตัวอย่าง ไม่ได้ส่งทุกค่า SID ในแต่ละเหตุการณ์ ปิดบัง SID และชื่อผู้ใช้บางรูปแบบก่อนส่ง แต่ไม่รับประกันลบข้อมูลส่วนตัวครบ ต้องตรวจ log ก่อนกด API ไม่มีการส่งอัตโนมัติ

## History และ Export

Save History เก็บล่าสุด 100 รายการใน `%LOCALAPPDATA%\WinSightAI\history.json` แบบ plaintext รวมขอบเขต scan และผลรายชุด เปิด History แล้วกดทำต่อได้ Export TXT วาง Local summary และผล AI ก่อนหลักฐานดิบ ห้ามส่ง history/log ส่วนตัวโดยไม่ตรวจ

## Source และการทดสอบ

Windows 10/11, Python 3.11–3.13 64-bit:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
.\.venv\Scripts\python.exe -m unittest -v test_core test_pathumma test_evidence test_scan_range test_citation
.\.venv\Scripts\python.exe -m PyInstaller --noconfirm --onedir --windowed --name WinSightAI --collect-all customtkinter --collect-all pythainlp app.py
```

ส่วน ML ใช้โมเดลผ่าน API ส่วน local เป็นกฎและการจัดกลุ่ม ไม่ใช่โมเดลที่ฝึกเอง ไม่อ้าง accuracy หรือสาเหตุยืนยัน ดู VALIDATION.md สำหรับผลทดสอบจริงและข้อจำกัดของรอบส่งมอบนี้
